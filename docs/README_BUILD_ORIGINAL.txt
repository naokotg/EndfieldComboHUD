终末地连携技 HUD v2.1 Beta - Build 包

用途
====
这是用于在 Windows 本机生成 EXE 的 build 包。
当前代码基于 v2.1-alpha5。

打包方法
========
1. 解压整个文件夹。
2. 双击 BUILD_EXE.bat。
3. 首次运行如果没有 PyInstaller，会自动安装。
4. 打包完成后 EXE 位于：

   dist\EndfieldCDHUD.exe

调试
====
如果正式 EXE 出现异常，可先运行：
START_DEBUG.bat

这样可以看到 Python 控制台报错，方便定位。

v2.1 Beta / 测试版
