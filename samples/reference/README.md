# Reference samples

These images are historical debug evidence, not a complete test dataset.

- `low_hp_alive_55_of_1974.png`
  Extremely low HP but still alive. This exposed the weakness of HP-only death
  detection.

- `death_icon_multi_lighting.jpg`
  Death-state icon observed across different lighting while moving.

- `out_of_combat_false_wake_alpha4.jpg`
  Example of the alpha4 out-of-combat false-wake problem.

- `battle_rois_reference.png`
- `outcombat_rois_reference.png`
  Annotated ROI references used while investigating bar presence.

Large future recordings should be placed under `samples/local/` and kept out of
Git unless there is a strong reason to preserve them.
